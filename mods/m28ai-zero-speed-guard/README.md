# M28AI Zero-Speed Projectile Guard

Небольшой симуляционный патч совместимости для M28AI v328. Он пропускает
расчёт уклонения от ракеты для снарядов, у которых в blueprint указано
`Physics.MaxSpeed <= 0`. Остальные снаряды обрабатываются штатным M28AI.
Для таких снарядов уклонение M28AI от ракет в этой функции отключено; физика
и blueprint снарядов не меняются.

Предполагаемый случай: артиллерия BRB2303 из BlackOps FAF: Unleashed имеет
категории, по которым M28AI относит её к TML; её снаряд CybranHailfire04
имеет `MaxSpeed = 0`. Это возможное объяснение предупреждений `Invalid args
to yield()` из лога матча 28087744, но журнал не подтверждает конкретный
снаряд. Патч не гарантирует устранения `bad allocation`.

## Требования и установка

Нужны Forged Alliance, FAF и M28AI. Для проверки скопируйте всю папку
`m28ai-zero-speed-guard` в каталог модов FAF и включите её вместе с M28AI
перед новым матчем. Для сетевого матча симуляционный мод нужен всем игрокам.
Исходный M28AI не изменяется. После обновления M28AI совместимость следует
перепроверить: патч написан по коду v328.

## Статус

Исходный код и путь хука проверены по локальным файлам; игра с патчем ещё не
запускалась. Проверьте загрузку хука в логе, поведение юнитов и отсутствие
повторных предупреждений, затем сравните использование памяти и стабильность.
