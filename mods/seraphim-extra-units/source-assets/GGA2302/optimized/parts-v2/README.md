# Sha’Veyr: rebuild by parts, 2026-11-07

LOD0: 2233 exported vertices / 4400 triangles / 6 bones.
LOD1: 371 vertices / 634 triangles / 6 bones.
Three shared 512x512 DXT5 textures, 1,049,040 bytes including all mips. Same textures shared by both LODs, counted once.

Rebuild uses the authoring scene ../../ShaVeyr.blend rather than repeatedly decimating the combined SCM. Circular muzzle parts resampled evenly from their original 80-segment profiles. Main muzzle rims use 20 segments; secondary rings use 12. Distant barrels use 8 segments; internal accelerator rings and small trim omitted in the far LOD. Shell/cheeks have individual polygon budgets; pedestal remeshed before reduction to avoid intersecting thin layers. 86 ornamental curves rasterized into the existing atlas team mask (Albedo.A) and metallic response rather than exported as geometry. Original filled pattern preserved. Raised ornament relief is lost; thin lines and small curves are softer at close zoom. Palette/emissive material mapping preserved.

Bone records and pivots match original SCM. Blueprint, scripts, damage, range, footprint and LOD thresholds unchanged. Wreck mesh unchanged; it shares material paths and therefore uses the updated textures. No game test performed. Verified binary indices, finite normals/coordinates, nondegenerate faces, bone transforms/hierarchy, budgets and DDS mip chains, and rendered exported models.

Before-v2.zip restores the previous unit directory (extract only for deliberate rollback). Original input archive is ../original-inputs.zip. Reproduction: extract that archive to work (work/original), then Blender 4.5.3 shaveyr_parts.py, Python texture_shaveyr_parts.py, Python validate_shaveyr_parts.py, Blender render_shaveyr_parts.py. SHAVEYR_OPT_WORK overrides work. Renderer requires decoded PNGs generated by texture script. Python numpy/Pillow needed. Scripts create runtime candidates, not automatic installation. Blender scene contains source and hidden LOD parts, not a game armature.
