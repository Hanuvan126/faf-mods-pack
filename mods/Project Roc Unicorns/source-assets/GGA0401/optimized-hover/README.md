# Dush’Nai — локальная оптимизация, 2026-11-07

LOD0: 8232 вершины / 9781 треугольник / 16 костей.
LOD1: 869 вершин / 1024 треугольника / 16 костей.
Ранее LOD0: 50080 / 69777 / 33, LOD1: 26335 / 37604 / 33, LOD2: 14285 / 20427 / 33.

17 неиспользуемых костей удалены. Сохранены root, MainYaw/MainPitch/MainMuzzle, две гондолы и десять точек эффектов. Исходные трансформации и иерархия этих костей проверены. Gameplay Lua и unit blueprint не изменены.

Узоры корпуса перенесены из геометрии в плоскую проекцию текстуры. На нижней поверхности корпуса проекция также повторяется. Дальний LOD сохраняет силуэт с более грубыми кольцами и кромками; предназначен только для удаленной камеры. Пороги: 240 и 700.

Новые карты: 3 × 2048×1024 и 3 × 512×256, DXT5 с независимым уменьшением каналов mipmaps, суммарно 8.5 MiB. Старые approved-карты не удалены: normal map используется останками. Старый LOD2 больше не подключён к живому юниту. Размер папки на диске поэтому не отражает снижение ресурсов живой модели.

`before-optimization.zip` — исходная папка юнита для отката. `optimization-inputs.zip` — входные SCM/DDS/PNG для пересборки; распаковать в `work` рядом со скриптами (получится work/original). Затем Blender -b --python optimize_dush_projection.py, Python dush_projection_textures.py, Python validate_dush_optimized.py, Blender -b --python render_dush_compare.py. Можно задать DUSH_OPT_WORK вместо work. Скрипты создают результат в work/runtime, но не устанавливают его в мод автоматически. Python требует numpy/Pillow; Blender 4.5.3. Рабочий blend содержит промежуточную геометрию, это не готовая сцена со скелетом для ручной анимации.

Проверены бинарные SCM, индексы, нормали, трансформации костей, зеркальность гондол, бюджеты вершин, DDS/mipmaps и рендеры экспортированных моделей. Проверка анимаций и переключения LOD непосредственно в FAF ещё не выполнена. В игру автоматически не копировалось. На GitHub не загружалось.
