Модель переработана по девяти предоставленным изображениям.

SiegeWalker.glb — модель со встроенными текстурами. Метры, Y вверх, орудия направлены по +Z.
SiegeWalker.obj + SiegeWalker.mtl + *_BaseColor.png — переносить вместе; OBJ содержит UV.
SiegeWalker_Preview.png, SiegeWalker_Front.png, SiegeWalker_OtherSide.png — три обзорных ракурса.

Наклонная клепаная башня, складчатые чехлы орудий, решетки и задние радиаторы,
наружная лестница, четырехопорная шарнирная ходовая часть, парные гидроцилиндры,
ступицы с крепежом, бронещитки ступней и диагональная маркировка.

Статическая геометрия без скелета и анимаций. Unity-префаб не создавался.

Крепления ног: четыре округлые выемки барбета с открытым сектором 200 градусов.
GLB содержит отдельные узлы Left_Front, Left_Rear, Right_Front, Right_Rear.
Центры узлов совпадают с вертикальными осями шарниров. В extras узлов записан
диапазон yaw_limits_degrees [-100, 100] вокруг оси Y; это метаданные для настройки
ограничений в редакторе или движке, а не воспроизводимая анимация.
Проверено 201 положение каждой ноги относительно геометрии барбета и направляющих.
