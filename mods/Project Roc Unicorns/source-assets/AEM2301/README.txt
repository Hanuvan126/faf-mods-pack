FAF test package: Aeon Twin Missile Turret (AEM2301)
Copy this entire AeonMissileTurret folder into your FAF mods directory and enable the simulation mod in a custom game.
For the first test, enable cheats and spawn AEM2301 through the unit creation menu (Alt+F2).
Check yaw, pitch, both muzzle origins, projectile flight and damage. Balance values are provisional.
No in-game test has been performed. No build-menu icon or optimized LOD1 is supplied yet.
Model and textures derive from Supreme Commander Forged Alliance UAB2101 by Gas Powered Games.
Use with your game installation; this package does not replace any original game files.
